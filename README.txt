FIT COACH - نسخة أولية قابلة للتجربة

1) افتح index.html في متصفح Chrome على الهاتف أو الكمبيوتر.
2) يمكنك تسجيل الوجبات والوزن ومحيط البطن ومتابعة مؤقت الصيام.
3) البيانات تحفظ محليًا في المتصفح على نفس الجهاز.

ملاحظة التثبيت:
هذه حزمة أولية وليست تطبيق Android APK. لتحويلها إلى تطبيق ويب قابل للتثبيت (PWA) بأيقونة وفتح مستقل، يجب رفع الملفات إلى استضافة HTTPS ثم فتح الرابط في Chrome واختيار (إضافة إلى الشاشة الرئيسية / Install app).
